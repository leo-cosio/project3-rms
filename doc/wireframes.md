## Pantallas del MVP

- `/` — Redirección al login si no hay sesión
- `/login` — Formulario de inicio de sesión
- `/admin` — Pantalla de administrador para crear usuarios nuevos
- `/admin/users` — Gestión de usuarios
- `/admin/menu` — Gestión de menú y precios
- `/staff` — Pantalla de los camareros para gestionar las comandas y mesas
- `/staff/:tableId` — Gestión de mesa para los camareros
- `/reception` — Recepción para gestionar las mesas, reservas y pagos
- `/reception/:tableId` — Gestión de mesa y pago para la recepción
